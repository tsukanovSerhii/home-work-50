# Домашнє завдання 50: Оптимізація React-додатків через мемоізацію

Цей проект створено за допомогою Vite та демонструє використання React Hooks для оптимізації продуктивності: `useMemo`, `useCallback`, та `React.memo`.

## Опис проекту

Додаток має преміальний "glassmorphism" дизайн і містить інтерактивну інформаційну панель (dashboard). Панель дозволяє користувачеві взаємодіяти з різними станами і наочно бачити, як мемоізація запобігає непотрібним перерахункам і ререндерам дочірніх компонентів.

Основні елементи:
- **`useMemo`**: Використовується для мемоізації результату "важких" обчислень, що запобігає зависанню UI при оновленні непов'язаних станів.
- **`useCallback`**: Використовується для мемоізації функції додавання нових елементів, щоб вона зберігала своє посилання між ререндерами батьківського компонента.
- **`React.memo`**: Використовується для мемоізації дочірнього компонента списку, щоб він не ререндерився, якщо його `props` не змінились.

## Інструкції зі встановлення та запуску

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/tsukanovSerhii/home-work-50.git
   ```

2. Перейдіть у директорію проекту:
   ```bash
   cd home-work-50
   ```

3. Встановіть залежності:
   ```bash
   npm install
   ```

4. Запустіть проект у режимі розробки:
   ```bash
   npm run dev
   ```

5. Відкрийте локальний сервер у вашому браузері (зазвичай [http://localhost:5173/](http://localhost:5173/)).
